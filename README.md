### SDR front end for teensy and teensy audio

This fronend board stacks on top of a teensyaudio board which iself is stacked on the teensy.

Teensy 4.0 is used, schematic is heavily inspired by the Elektor board: https://www.elektormagazine.fr/labs/software-defined-radio-sdr-shield-for-arduino-150515-1

The differences are:

The frequency is not divided by 4 to make quadrature signals (no 7474 flipflops), rather the quadrature will have to be generated by the si5351.
A provision for an external oscillator input is made, it uses a separate SMA

Cautions:

The current PCB has not been updated to reflect the current schematics.

Problems with previous schematic (and current PCB)
The output level can be high enough to destroy the audio shield inputs, make sure the input level is limited.
Protection resistors have been added in schematic V2
the + and - input of 2 op amps are inverted in schematic V1, corrected in V2.
